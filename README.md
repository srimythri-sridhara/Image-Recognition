# 👁️ VisionAI — Image Recognition

An AI-powered image recognition web application built with **Python, TensorFlow, MobileNetV2, and Streamlit**.

## ✨ Features

- 🖼️ Upload JPG, JPEG, or PNG images
- 🤖 AI-powered image classification
- 🎯 Displays the predicted object
- 📊 Shows prediction confidence
- 🔝 Displays Top 5 predictions
- ⚡ Fast and interactive interface
- 🎨 Modern, responsive Streamlit UI

## 🛠️ Technologies Used

- Python
- TensorFlow
- MobileNetV2
- Streamlit
- NumPy
- Pillow

## 🧠 How It Works

1. Upload an image.
2. The image is resized to the required input size.
3. MobileNetV2 processes the image.
4. The model compares the image with ImageNet classes.
5. The application displays the most likely predictions and confidence scores.
